Проект «Сетевой чат»
Сложность: 4
Примечание: проект является продолжением чата, реализованного на курсе
Цель работы: применить полученные на курсе знания
Задание: реализовать клиент-серверное приложение «Сетевой чат» на java.io, которое имеет следующие возможности:
#### Серверная часть:
1. Запуск ServerSocket, прослушивание определенного порта и ожидание подключений
2. Обработка каждого подключения в отдельном потоке
3. Получение от клиентов сообщений: служебных команд и сообщений чата
4. Возможность регистрации и авторизации клиентов, с хранением данных о клиентах в базе данных
5. Рассылка сообщений всем авторизованным клиентам
6. Сервер к сообщениям должен добавлять время рассылки
7. Поддержка личных сообщений
8. Возможность изменения ника клиента по его запросу
9. Рассылка списка активных клиентов
10. Автоматическое отключение клиентов, которые не активны более 20 минут
11. Поддержка ролей пользователей (admin, user)
12. Возможность банить клиентов, баны могут быть по времени или перманентные (так может делать админ)
13. Возможность остановить сервер командой /shutdown
14. Возможность назначить пользователю роль администратора
15. Добавить систему отдельных комнат.
    15.1 Есть общая комната куда все клиенты попадают по-умолчанию.
    15.2 Любой клиент может создать собственную комнату, и повесить на нее пароль.
    15.3 Можно запрашивать список комнат.
    15.4 Можно заходить в созданные комнаты, командой /enter [room_name] [room_pass, если он есть].
    15.5 В одно время пользователь может находиться только в одной комнате.
    15.6 При подключении можно ему отправлять историю сообщений из этой комнаты.
    15.7 Если в комнату давно никто не заходил (7+ дней), то она удаляется.
    15.8 У каждой комнаты есть владелец, один юзер не может владеть более чем 5 комнатами.
    15.9 Владелец комнаты при помощи команды /kick может отключить любого клиента из комнаты, а администратор из Общей комнаты.
16. Реализовать фильтр плохих слов.
17. Защита от спам-сообщений, нельзя в [не более 5 сообщений за 10 секунд] отправлять больше N сообщений
18. Запоминать когда клиент был последний раз в сети, с возможностью, чтобы другие клиенты могли узнавать эту информацию: /last_activity [имя_пользователя]

#### Клиентская часть:
1. Возможность подключиться к серверу
2. Возможность отправлять и получать сообщения
3. Возможность отключаться от сервера с помощью команды /exit

####  Все служебные действия могут выполняться через обычные сообщения, начинающиеся с /
/reg логин пароль имя  – Регистрация нового пользователя - /reg user1 123 UserName
/auth логин пароль  – Вход в существующий аккаунт  - /auth admin admin
/help - Показать список команд и текущую роль - /help
/w ник сообщение – Отправить личное сообщение - /w user1 Привет!
/users – список активных клиентов  исключить
/exit – Отключиться от чата - /exit
/logout - Выйти из учётной записи (остаться на сервере) - /logout
/changenick новый_ник – Сменить ник  - /changenick SuperUser
/lastactivity ник - Узнать, когда пользователь был в сети - /lastactivity user1
/whoami - Показать свой текущий ник и роль	-  /whoami

/kick ник	- Исключить пользователя: в общей комнате – полное отключение	/kick user1
/add_admin ник	- Назначить администратором	/add_admin user1
/remove_admin ник	- Снять права администратора	/remove_admin user1
/shutdown	- Остановить сервер	/shutdown
/ban ник [минуты] [причина]	- Забанить пользователя. Без минут – перманентный бан.	/ban user1 10 спам
/unban ник	 - Снять бан	/unban user1

/listrooms - Показать комнаты - /listrooms
/createroom имя [пароль] - Создать комнату (пароль необязателен) - /createroom GameRoom 123
/enter имя [пароль] - Войти в комнату (если есть пароль – указать) - /enter GameRoom 123
/deleteroom имя  - Удалить комнату - /deleteroom GameRoom
/leaveroom - Покинуть текущую комнату и вернуться в общую - /leaveroom
/invite имя_комнаты ник - Пригласить пользователя в комнату - /invite GameRoom user1
/myinvites - Посмотреть свои активные приглашения - /myinvites
/decline имя_комнаты - 	Отклонить приглашение	- /decline MyRoom
/roominfo [комната]	 - Информация о комнате (владелец, пароль, дата создания). Без параметра – о текущей.	/roominfo GameRoom

/auth admin admin -  первый админ
